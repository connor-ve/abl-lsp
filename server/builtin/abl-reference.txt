# ABL built-in functions, system handles and handle attributes/methods.
#
# Format:
#   @functions                          following entries are built-in functions
#   @handle KIND [system=NAME,NAME]     following entries are attributes/methods of a handle kind;
#                                       `system=` lists the system handles of that kind
#   NAME(p AS TYPE, [opt AS TYPE], ...) AS TYPE     a function or method; [..] marks optional
#                                                   parameters, `...` more of the same
#   NAME AS TYPE                        an attribute (or a function without parentheses)
#   HANDLE:KIND as a type               a handle of that kind (used to type chains)
#   indented lines                      documentation
#
# Written from the OpenEdge documentation; correct entries here as you find gaps.
